## Memaster Workflow

This project uses Memaster for task and project management.

**At the beginning of each conversation in this project, run `memaster instructions overview` before answering or taking action. Re-read it only if you have not read it yet in the current conversation.**

Use the overview to decide whether to search, read, create, or update Memaster tasks.

Before task lifecycle actions, read the matching detailed guide:
- `memaster instructions task-creation` before creating or splitting tasks
- `memaster instructions task-execution` before planning, changing status or assignee, adding a plan or implementation notes, or implementing task work
- `memaster instructions task-finalization` before checking acceptance criteria, writing final summaries, or moving tasks to terminal statuses

Use `memaster <command> --help` before running unfamiliar commands. Help shows options, fields, and examples.

Do not edit Memaster task, draft, document, decision, or milestone markdown files directly. Use the `memaster` CLI so metadata, relationships, and history stay consistent.
