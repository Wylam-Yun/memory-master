# 前端信息架构与 UI/UX 调研计划

目标：仅以 Memory Master 当前仓库的功能和普通用户场景为依据，重新确定页面内容、导航与交互，给出可审阅线框图和视觉规范。本轮不实现产品代码，不直接替换已审阅的 SPEC。

## 调研范围

1. 当前产品事实：库项目界面、路由、API、MCP、权限、首次使用；辨别旧版仓库内界面与当前产品入口。
2. 六个指定设计站点：进入具体产品案例和相关分类，记录可迁移规律及不适用部分；对受限内容注明证据范围。
3. 相近产品与交互依据：只研究导航、阅读、任务、资料、状态反馈；参考产品业务不进入 Memory Master 需求。
4. 独立信息架构：页面清单、层级、每页内容、关键流程、异常状态、响应式规则及 2–3 个合理方案。

综合输出：功能证据清单、带链接研究记录、页面设计报告与 ASCII 线框图、布局和组件规范、后续实施顺序与验收。事实、设计建议、待确认需求分别标注。

执行方式：独立完成；仅将相互独立的读取与搜索工具调用并发。
